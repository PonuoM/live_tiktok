# เกมร้านผีกะศุกร์13 สำหรับ TikTok LIVE

คนดูพิมพ์คอมเมนต์แล้วได้ตัวละคร 8bit เดินในร้าน ไลค์ ของขวัญ และการกดติดตามมีผลกับเกม
1 คืนในเกมยาว 3 นาที (เที่ยงคืนถึง 06:00) เหตุการณ์ในคืนมีลูกค้าปริศนาให้โหวต 1 คน 2 ผี ไฟดับ นางรำ (ต้องพิมพ์ "ไม่มอง") และผีใหญ่ตอนตีห้า

## ใช้งาน
```
cd tools/live-game
npm install                 # ครั้งแรกครั้งเดียว
node server.js <ชื่อบัญชี>   # ชื่อบัญชี TikTok ที่กำลังไลฟ์ ไม่ต้องใส่ @
node server.js --demo       # ไม่ต่อไลฟ์ เปิด http://127.0.0.1:4192/?demo=1 ดูคนดูจำลอง
```
หน้าเกมอยู่ที่ `http://127.0.0.1:4192/` ถ้าบัญชียังไม่ได้ไลฟ์ เซิร์ฟเวอร์จะลองต่อใหม่เองทุก 30 วินาที จึงเปิดก่อนกดเริ่มไลฟ์ได้
คอนโซลพิมพ์สถิติทุก 10 วินาที: จำนวนคอมเมนต์ ไลค์ ของขวัญ คนดู และดีเลย์ (ทดสอบ 13 พ.ย. 2026 ได้ราว 1.2-2.5 วินาที)

## ตั้งค่าใน TikTok LIVE Studio
1. เพิ่มแหล่งภาพแบบ Link แล้ววาง `http://127.0.0.1:4192/` ตั้ง Custom resolution 1080x1920 แล้วกดให้พอดีจอ
2. ถ้าไลฟ์จากคอมบังคับให้มีกล้อง ให้วางกล้องไว้ชั้นล่างสุด แล้วให้ภาพเกมทับเต็มจอ จะได้ไม่เห็นหน้า

## ของขวัญ (แบ่งตามราคาเหรียญ)
| เหรียญ | ผล |
|---|---|
| ต่ำกว่า 30 (เช่น กุหลาบ) | ไฟฉาย ผีเข้าใกล้ไม่ได้ 30 วิ ส่งรัวจะต่อเวลา |
| 30-99 | ยันต์ ช่วยคนที่โดนจับคนล่าสุดกลับมา หรือกันผี 40 วิ |
| 100-298 | กล้องวงจรปิด เห็นหน้าจริงของลูกค้าปริศนา |
| 299 ขึ้นไป | เพลงร้าน ผีทุกตัวหยุด 10 วิ |
ตอนผีใหญ่ ของขวัญทุกชิ้นช่วยดันผีออก (เหรียญ x8) กดติดตามได้ยันต์ฟรี 30 วิ

## ข้อควรรู้
- ตัวเชื่อมคือ `tiktok-live-connector` (ไม่เป็นทางการ อ่านไลฟ์สาธารณะจากชื่อบัญชี ไม่ใช้รหัสผ่านหรือคุกกี้) การเซ็นคำขอผ่าน Euler Stream แบบฟรี
- ห้ามเปิด `enableExtendedGiftInfo` เพราะการดึงรายชื่อของขวัญต้องใช้แพ็กเกจ Business ของ Euler ทำให้ต่อไม่ได้ทั้งหมด
- ช่องข้อมูลจริง (v2.5.0): ข้อความ `content` ชื่อบัญชี `user.displayId` ไลค์ `count` คนดู `total` ของขวัญ `gift.diamondCount` กับ `repeatCount` แบบสะสม
- ถ้า TikTok เปลี่ยนรูปแบบข้อมูล คอมเมนต์อาจหายจนต้องอัปเดตแพ็กเกจ
- เป้าไลค์ตอนไฟดับและผีใหญ่ลดตามจำนวนคนในร้าน และคอมเมนต์ช่วงนั้นนับเป็นแต้มด้วย ร้านรับคนได้ 60 คนพร้อมกัน
